# Security Policy

## Reporting a vulnerability

Report security issues in the Crossdeck Node SDK privately to **security@cross-deck.com**. Include
reproduction steps and the affected version. We aim to acknowledge within two business days.

Please do not open a public issue, pull request or discussion for a security report — that
discloses the problem to everyone before there is a fix.

## Scope

This policy covers this repository and anything published from it. For how Crossdeck handles
keys, access and customer data across the platform, see the
[security overview](https://cross-deck.com/legal/security/).

Implementation details for this package are documented in the
[developer documentation](https://cross-deck.com/docs/node-sdk/).

## Supported versions

Security fixes land on the latest published release. Please upgrade before reporting a problem
against an older version — the [changelog](https://cross-deck.com/docs/changelog/) records what
changed in each one.
